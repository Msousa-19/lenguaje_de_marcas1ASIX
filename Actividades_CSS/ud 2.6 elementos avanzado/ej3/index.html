El contenido que CSS crea por su cuenta

Qué son los pseudoelementos

Un pseudoelemento permite dar estilo a una parte concreta de un elemento, como su primera letra o su primera línea, sin tener que añadir etiquetas extra al documento. Gracias a ellos el HTML se mantiene limpio y toda la presentación queda en la hoja de estilos, donde debe estar.

Otros pseudoelementos no seleccionan algo que ya existe, sino que generan contenido nuevo antes o después de un elemento. Ese contenido no aparece en el código HTML ni lo leen los buscadores, por lo que conviene usarlo solo para adornos y no para información importante que el lector necesite.

Para qué sirven en la práctica

En una web real se usan para dibujar iconos pequeños, añadir flechas a los enlaces externos, crear barras decorativas bajo los títulos o mostrar ayudas emergentes. Casi siempre se combinan con selectores de atributo y con pseudoclases como el hover, que cambian el aspecto cuando el usuario interactúa con la página.

  • Resaltar la primera letra de un párrafo
  • Cambiar el color de la selección
  • Añadir símbolos delante de una lista
  • Marcar los enlaces que abren otra pestaña
