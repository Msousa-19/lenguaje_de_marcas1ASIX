Ficha técnica: Python

Python es un lenguaje de programación creado por Guido van Rossum. Su primera versión se publicó el 20 de febrero de 1991.

Se puede programar en un IDE. Para ejecutar un programa usa python programa.py. Para guardar los cambios pulsa Ctrl + S.

El cuadrado de un número se escribe x2.
