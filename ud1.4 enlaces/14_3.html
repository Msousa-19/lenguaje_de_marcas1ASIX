Estructura de un documento HTML

HTML son las siglas de HyperText Markup Language. Es un lenguaje para crear documentos formados por marcas que el navegador interpreta, y como es hipertexto permite definir enlaces que llevan de un documento a otros.

Todo documento empieza con la declaración DOCTYPE y tiene como elemento raíz <html>, que contiene dos partes: <head>, con información del documento como el <title> (de uso obligatorio y visible en el navegador), las etiquetas <meta> o las hojas de estilo, y <body>, con el contenido de la página.

Formato de texto

La forma más sencilla de estructurar un texto es separarlo en párrafos con <p> y poner títulos con los encabezados <h1> a <h6>, de mayor a menor graduación. Los encabezados se muestran en negrita con un tamaño de fuente concreto, y al terminar se genera un salto de línea automáticamente.

Para marcar partes importantes del texto hay etiquetas como strong para lo importante, em para enfatizar, del para el texto tachado o mark para remarcarlo. Si se aplican varias etiquetas a un mismo texto, se cierran en orden inverso al que se abrieron.

Imágenes

Las imágenes se insertan con la etiqueta <img> y su atributo src, que indica la URL de la imagen, relativa o absoluta. Es un elemento vacío, por lo que no necesita etiqueta de cierre, y es un elemento de tipo línea. Los formatos reconocidos por la mayoría de navegadores son jpg, gif, png y SVG.

Todas las imágenes deben llevar el atributo alt, con un texto alternativo que se muestra si la imagen no se encuentra. El tamaño se controla con width y height, en píxeles o en porcentaje, y el borde se añade con la propiedad CSS border dentro del atributo style.

Enlaces

Los enlaces se crean con la etiqueta <a> y su atributo href, que indica el destino. Tienen tres partes: el destino, el rótulo, que es la parte visible para el usuario, y el objetivo, que con target="_blank" hace que la página se abra en una pestaña nueva.

Las URL absolutas incluyen protocolo, servidor y ruta, mientras que las relativas omiten alguna parte. Es aconsejable usar URL relativas, porque si algún día movemos el sitio web no hay que cambiar el código. Para saltar a un punto de la misma página se pone un id en el destino y en el href el símbolo # seguido de ese id, que es justo lo que hace este índice.
